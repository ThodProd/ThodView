# ThodView

Быстрый офлайн-просмотрщик изображений для Windows и [ThodHUB](https://github.com/ThodProd/ThodHUB). Открывает форматы через встроенный ffmpeg, не отправляет файлы в сеть и не требует отдельной установки .NET.

## Возможности

- **Почти все форматы изображений** — PNG, JPEG, WebP, AVIF, HEIC/HEIF, JXL, JPEG 2000, TIFF, GIF, BMP, PSD, TGA, EXR, HDR, DDS, ICO, PNM, QOI, RAW-контейнеры и другие, которые умеет читать ffmpeg. Если ffmpeg не справился, включается встроенный декодер Windows.
- **Масштаб к курсору** — колесо мыши приближает именно ту точку, на которую смотрит курсор. При увеличении изображение можно тянуть мышью.
- **Стрелки в папке** — если рядом есть другие изображения, при наведении курсора к нижнему краю появляются кнопки `‹` и `›`. Работают также клавиши `←` и `→`.
- **Правка** — поворот влево/вправо, отражение по горизонтали/вертикали и обрезка вынесены в отдельную панель с понятными символами.
- **Метаданные** — просмотр всех тегов EXIF, XMP, IPTC, GPS, PNG и других форматов. Можно изменить значение, добавить свой тег, удалить выбранные теги, стереть всё, скопировать список в буфер обмена.
- **Открыть папку** — маленькая кнопка в строке состояния и пункт в настройках выделяют текущий файл в Проводнике.
- **Открыть с помощью / по умолчанию** — ThodView регистрируется в Windows для изображений. В настройках есть кнопка, которая открывает системный выбор программы по умолчанию.
- **Светлая и тёмная темы** — кнопка в настройках, настройка запоминается.

Изменения пикселей сохраняются через «Сохранить как…» в PNG или JPEG. Метаданные записываются в текущий файл через ExifTool.

## Установка

1. Откройте ThodHUB → «Магазин».
2. Найдите **ThodView** и нажмите «Установить».
3. Запустите программу из библиотеки хаба.

Вручную: скачайте ZIP из [Releases](https://github.com/ThodProd/ThodView/releases), распакуйте в отдельную папку и установите через ThodHUB (пакет содержит `manifest.json` в корне).

Требования: Windows 10/11 x64, ThodHUB 0.1.0+. Отдельный .NET Runtime не нужен — приложение публикуется self-contained.

## Программа по умолчанию

Windows 10/11 не разрешает приложению молча назначить себя обработчиком всех изображений. Кнопка **«Открывать изображения…»** в настройках:

1. регистрирует ThodView в `HKCU\Software\Classes` и в списке «Открыть с помощью»;
2. открывает системные настройки, где нужно выбрать ThodView для нужных расширений.

Регистрация действует для текущего пользователя. После переноса папки с программой или обновления версии через хаб путь к `ThodView.exe` может измениться — тогда нажмите кнопку ещё раз.

## Разработка

```
src/ThodView        — .NET 10 WPF, self-contained win-x64
hub/manifest.json   — манифест standalone-модуля
scripts/build.ps1   — publish, загрузка ffmpeg/ExifTool, упаковка
assets/thodview.ico — иконка приложения
```

Сборка:

```powershell
.\scripts\build.ps1
```

Без параметров скрипт скачает закреплённые версии ffmpeg и ExifTool в `.cache` и проверит SHA-256. Результат — `artifacts/thodview-<version>-win-x64.zip` и `artifacts/thodhub-release.json`.

Для локальной сборки можно передать уже скачанные архивы:

```powershell
.\scripts\build.ps1 -FfmpegZip .\ffmpeg-9.0.2-essentials_build.zip -ExifToolZip .\exiftool-13.59_64.zip
```
