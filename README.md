# ThodView

Офлайн-просмотрщик изображений для Windows 10/11 x64. Распакуйте ZIP в постоянную папку и запустите `ThodView.exe`. Папка `runtime` содержит FFmpeg и ExifTool.

ThodView также доступен в каталоге ThodHUB. Установка и обновление выполняются в хабе, а просмотрщик открывается в отдельном окне. Оба способа запуска используют настройки из `%LOCALAPPDATA%\ThodHUB\Data\thodview`.

## Просмотр и правка

- Открывайте изображения перетаскиванием, через `Ctrl+O` или аргументом командной строки. Для файла с необычным расширением выберите «Все файлы».
- Колесо масштабирует к курсору. В увеличенном виде изображение можно двигать мышью. При обратной прокрутке масштаб останавливается на исходном вписывании и изображение центрируется. `0` вписывает в окно, `1` включает попиксельный масштаб с учётом нижнего предела.
- `←` и `→` перелистывают изображения в папке. `Page Up` и `Page Down` переключают страницы многостраничного файла. `Пробел` приостанавливает анимацию.
- Карандаш открывает поворот, отражение и обрезку. `Ctrl+S` сохраняет текущий кадр в PNG, JPEG, WebP, BMP, TIFF или QOI. В JPEG прозрачность заменяется белым фоном.
- Кнопка `OCR` рядом с карандашом подсвечивает распознанные слова. Нажмите на слово или выделите область левой кнопкой мыши, скопируйте текст через `Ctrl+C` и выйдите из режима через `Esc`. OCR работает офлайн и использует установленные языковые компоненты Windows. Язык можно выбрать в режиме OCR.
- Чтобы изменить размер окна, потяните за любой край или угол.
- `M` открывает просмотр и правку метаданных исходного файла через ExifTool. `F` выделяет файл в Проводнике. Тему можно сменить в меню или клавишей `T`.

## Форматы

Сигнатуры JPEG, PNG, GIF, WebP, JPEG XL, TIFF, PSD и многих других форматов распознаются независимо от расширения. Для форматов без надёжной сигнатуры исходное расширение может потребоваться.

Собственные декодеры открывают распространённые форматы, SVG/SVGZ и JPEG XL. Системные кодеки WIC и FFmpeg расширяют покрытие, включая HEIF/HEIC, AVIF, PSD и JPEG 2000. Анимация поддерживается для GIF, APNG, WebP и JPEG XL, а страницы TIFF открываются через WIC. Доступность RAW зависит от кодеков Windows и встроенного превью камеры. FFmpeg открывает первый кадр форматов, декодируемых этим способом.

Просмотр и экспорт используют восьмибитное представление RGBA. Предел растрового декодирования составляет 160 мегапикселей и 40 000 пикселей по стороне. Для длинных или тяжёлых анимаций приложение показывает первый кадр и сообщает об этом в строке состояния.

## Интеграция с Windows

При первом запуске из распакованного ZIP ThodView регистрируется для текущего пользователя и добавляет пункт **Открыть в ThodView** в меню Проводника. Шестерёнка → **Открывать изображения…** позволяет выключить этот пункт, повторить регистрацию и открыть системное окно выбора обработчика по умолчанию.

После назначения ThodView типу файлов Windows использует значок просмотрщика для этого типа. Миниатюры обрабатывает Проводник. В Windows 11 классическая команда доступна через **Показать дополнительные параметры**. При переносе программы повторите регистрацию из нового расположения.

Команды для регистрации и удаления регистрации текущей копии:

```powershell
.\ThodView.exe --register-integrations
.\ThodView.exe --default-viewer
.\ThodView.exe --uninstall-context
```

## Сборка

Нужен стабильный Rust для Windows x64. Для MSVC потребуются Visual Studio Build Tools с Windows SDK, для GNU — MinGW-w64 с `gcc` и `windres`.

```powershell
cargo test --locked
.\scripts\build.ps1
```

Скрипт проверяет SHA-256 архивов FFmpeg и ExifTool. Переносимый ZIP попадает в `artifacts`, пакет для хаба и `thodhub-release.json` — в `artifacts/hub`. Тег `vX.Y.Z` публикует переносимый ZIP и создаёт выпуск `hub-vX.Y.Z` для каталога. Версия должна совпадать в `Cargo.toml` и `hub/manifest.json`.

Параметры `-FfmpegZip` и `-ExifToolZip` принимают уже скачанные архивы закреплённых версий. Сборка через Cargo запускает просмотрщик с собственными декодерами. Для доступа к FFmpeg и ExifTool используйте собранный пакет, установленные инструменты в `PATH` или переменные `THODVIEW_FFMPEG` и `THODVIEW_EXIFTOOL`.
